구조분해와 스프레드

리액트 코드에서 매 줄 나오는 { }, [ ], ... 문법을 개념과 예제로 정리했어요. 예제는 그대로 복사해서 실행해 볼 수 있어요.

Part 1

개념

구조분해는 꺼내기, 스프레드는 펼치기예요. 같은 ... 모양이 받는 쪽에 오면 나머지 모으기(rest)가 돼요.

구조분해: 객체에서 꺼내기 { }

const user = { name: "민지", age: 25 };

// 구조분해 없이
const name = user.name;
const age = user.age;

// 구조분해
const { name, age } = user;

변수 이름은 객체의 키 이름과 같아야 해요. 이름을 바꾸려면 :, 기본값을 주려면 =를 써요. 기본값은 값이 undefined일 때만 적용돼요.

const { name: userName } = user;   // user.name을 userName이라는 이름으로 꺼냄
const { city = "서울" } = user;    // user.city가 없으면 "서울"

구조분해: 배열에서 꺼내기 [ ]

배열은 키가 없어서 순서대로 꺼내요. 이름은 마음대로 지어도 돼요.

const colors = ["red", "green", "blue"];
const [first, second] = colors;    // first = "red", second = "green"
const [, , third] = colors;        // 앞의 둘은 건너뛰기 → "blue"

useState가 바로 이 문법이에요.

const [count, setCount] = useState(0);
// useState가 [현재 값, 값을 바꾸는 함수] 배열을 돌려주고
// 그 순서대로 count, setCount라는 이름으로 꺼낸 것

구조분해: 함수 매개변수에서 바로 꺼내기

리액트에서 가장 많이 보는 모양이에요.

// props를 통째로 받아서 쓰기
function Card(props) {
  return <h2>{props.title} - {props.price}원</h2>;
}

// 매개변수 자리에서 바로 구조분해
function Card({ title, price }) {
  return <h2>{title} - {price}원</h2>;
}

// 기본값도 가능
function Card({ title, price = 0 }) { ... }

({ title, price })의 { }는 객체를 만드는 게 아니라, 받은 객체(props)에서 꺼낸다는 뜻이에요.

스프레드: 배열과 객체 펼치기 ...

const a = [1, 2, 3];

const copy   = [...a];            // [1, 2, 3]  새 배열로 복사
const added  = [...a, 4];         // [1, 2, 3, 4]  뒤에 추가
const front  = [0, ...a];         // [0, 1, 2, 3]  앞에 추가
const merged = [...a, ...[7, 8]]; // [1, 2, 3, 7, 8]  합치기

const user = { name: "민지", age: 25 };

const copy2   = { ...user };                // 복사
const older   = { ...user, age: 26 };       // age만 바꾼 새 객체
const withJob = { ...user, job: "개발자" }; // 속성 추가

객체에서 같은 키가 겹치면 뒤에 오는 값이 앞의 값을 덮어써요. 그래서 순서가 결과를 바꿔요.

age: 26 
{ ...user, age: 26 }
age: 25 
{ age: 26, ...user }

리액트에서 스프레드가 꼭 필요한 이유

state를 바꿀 때는 원본을 고치지 않고 새 배열이나 새 객체를 만들어서 넘겨야 해요. 리액트는 참조(주소)가 바뀌었는지를 보고 다시 렌더링할지 정하기 때문이에요.

버그 
items.push(newItem);
setItems(items);
정상 
setItems([...items, newItem]);

이전 값을 기준으로 바꿀 때는 앞에서 배운 함수형 업데이트와 함께 써요.

setItems((prev) => [...prev, newItem]);
setUser((prev) => ({ ...prev, age: prev.age + 1 }));

화살표 함수가 객체를 바로 돌려줄 때는 ({ ... })처럼 소괄호로 감싸야 해요. 안 감싸면 { }를 함수 본문으로 오해해요.

삭제와 수정은 filter, map을 같이 써요.

// 삭제: 조건에 맞는 것만 남긴 새 배열
setItems(items.filter((item) => item.id !== targetId));

// 수정: 해당 항목만 새 객체로 바꾼 새 배열
setItems(items.map((item) =>
  item.id === targetId ? { ...item, done: true } : item
));

같은 ...인데 받는 쪽에 오면 rest

// 구조분해에서 나머지 모으기
const { name, ...rest } = { name: "민지", age: 25, city: "서울" };
// name = "민지", rest = { age: 25, city: "서울" }

// 함수 인자 모으기
function sum(...nums) { return nums.reduce((a, b) => a + b, 0); }
sum(1, 2, 3);   // 6

리액트에서는 props를 그대로 전달할 때 자주 써요.

function Button({ label, ...rest }) {
  return <button {...rest}>{label}</button>;
  // onClick, disabled 같은 나머지 props를 button에 그대로 전달
}

<Button label="저장" onClick={handleSave} disabled />

주의할 점

스프레드는 얕은 복사예요. 한 겹만 복사하고, 안쪽 객체는 같은 것을 공유해요.

const a = { profile: { city: "서울" } };
const b = { ...a };
b.profile.city = "부산";
console.log(a.profile.city);   // "부산"  a도 같이 바뀜

// 안쪽까지 바꿀 때는 안쪽도 펼쳐요
setUser({ ...user, profile: { ...user.profile, city: "부산" } });

undefined나 null을 구조분해하면 에러가 나요. 서버에서 받아오는 중이라 값이 아직 없을 수 있다면 const { name } = user ?? {};처럼 대비해요. 기본값(= "서울")은 undefined일 때만 적용되고 null에는 적용되지 않아요.

Part 2

초보자용 예제

1객체 구조분해 (기본)

const student = { name: "민지", age: 25, city: "서울" };

const { name, age } = student;

console.log(name);   // "민지"
console.log(age);    // 25

student.name, student.age를 매번 쓰는 대신 name, age라는 변수로 한 번에 꺼낸 거예요. 이름 바꾸기와 기본값도 같이 볼게요.

const { name: studentName, country = "한국" } = student;

console.log(studentName);   // "민지"  (name을 studentName이라는 이름으로 꺼냄)
console.log(country);       // "한국"  (student에 country가 없어서 기본값이 쓰임)

2배열 구조분해 (useState의 정체)

function getUser() {
  return ["민지", 25];   // 배열을 돌려주는 함수
}

const [userName, userAge] = getUser();
console.log(userName);   // "민지"
console.log(userAge);    // 25

useState(0)도 [현재 값, 값을 바꾸는 함수] 배열을 돌려주고, 우리는 그걸 순서대로 count, setCount라는 이름으로 꺼내는 거예요. 그래서 [value, setValue]로 이름을 지어도 똑같이 동작해요.

3props 구조분해와 스프레드로 넘기기

// props 객체에서 필요한 것만 꺼내고, soldOut은 안 오면 false
function ProductCard({ name, price, soldOut = false }) {
  return (
    <div>
      <h3>{name}</h3>
      <p>{price.toLocaleString()}원</p>
      {soldOut && <p>품절</p>}
    </div>
  );
}

function App() {
  const monitor = { name: "모니터", price: 190000 };

  return (
    <div>
      <ProductCard name="키보드" price={45000} />
      <ProductCard name="마우스" price={20000} soldOut={true} />
      <ProductCard {...monitor} />   {/* name={monitor.name} price={monitor.price}와 같은 뜻 */}
    </div>
  );
}
  • function ProductCard({ name, price })는 props.name, props.price를 쓰는 대신 매개변수 자리에서 바로 꺼낸 거예요.
  • <ProductCard {...monitor} />는 객체의 키와 값을 props로 하나씩 펼쳐서 넘겨요.

4할 일 목록 만들기 (배열 state와 스프레드)

추가는 [...todos, 새 항목], 삭제는 filter를 써요.

import { useState } from "react";

function TodoList() {
  const [todos, setTodos] = useState([
    { id: 1, text: "빨래하기" },
    { id: 2, text: "리액트 공부" },
  ]);
  const [input, setInput] = useState("");

  const handleAdd = () => {
    if (input.trim() === "") return;
    setTodos([...todos, { id: Date.now(), text: input }]);  // 기존 + 새 항목
    setInput("");
  };

  const handleDelete = (id) => {
    setTodos(todos.filter((todo) => todo.id !== id));       // 지울 것만 빼고 새 배열
  };

  return (
    <div>
      <input value={input} onChange={(e) => setInput(e.target.value)} />
      <button onClick={handleAdd}>추가</button>

      <ul>
        {todos.map(({ id, text }) => (        // 여기서도 구조분해
          <li key={id}>
            {text}
            <button onClick={() => handleDelete(id)}>삭제</button>
          </li>
        ))}
      </ul>
    </div>
  );
}

이번에 배운 것이 전부 들어 있어요.

  • useState는 배열 구조분해예요.
  • [...todos, {...}]는 배열 스프레드예요.
  • ({ id, text }) =>는 객체 구조분해예요.
  • onClick={() => handleDelete(id)}는 인자를 넘길 때 화살표 함수로 감싸는 거예요. 처음에 질문하셨던 바로 그 부분이에요.

5프로필 수정하기 (객체 state와 스프레드)

function ProfileEditor() {
  const [user, setUser] = useState({ name: "민지", age: 25, city: "서울" });

  return (
    <div>
      <p>{user.name} / {user.age}살 / {user.city}</p>

      <button onClick={() => setUser({ ...user, age: user.age + 1 })}>
        나이 +1
      </button>

      <button onClick={() => setUser({ ...user, city: "부산" })}>
        부산으로 이사
      </button>
    </div>
  );
}

{ ...user, age: user.age + 1 }은 "user를 통째로 복사하고, age만 새 값으로 덮어써라"는 뜻이에요. name과 city는 그대로 유지돼요.

만약 setUser({ age: 26 })이라고만 쓰면 name과 city가 사라져요. 객체 state는 통째로 교체되기 때문이에요. 그래서 ...user로 나머지를 복사해 오는 거예요.

Part 3

연습문제와 정리

결과를 먼저 예상해 보고 정답을 열어 보세요.

문제 1 
const { a, b = 5 } = { a: 1 };
console.log(a, b);

정답: 1 5
a는 값이 있고, b는 없어서 기본값 5가 쓰여요.

문제 2 
const arr = [1, 2, 3];
const arr2 = [...arr, 4];
console.log(arr, arr2);

정답: [1, 2, 3] [1, 2, 3, 4]
원본 arr는 그대로고, 새 배열 arr2만 4가 추가돼요.

문제 3 
const x = { n: 1, m: 2 };
const y = { ...x, n: 10 };
console.log(y);

정답: { n: 10, m: 2 }
뒤에 온 n: 10이 앞의 값을 덮어써요.

문제 4 
const x = { n: 1, m: 2 };
const z = { n: 10, ...x };
console.log(z);

정답: { n: 1, m: 2 }
이번엔 ...x가 뒤에 와서 n: 10을 n: 1로 덮어써요. 순서가 결과를 바꿔요.

문법방향예시용도
구조분해꺼내기const { a, b } = obj객체나 배열에서 값을 변수로
스프레드펼치기[...arr, x], { ...obj, k: v }복사, 추가, 일부만 덮어쓰기
나머지(rest)모으기const { a, ...rest } = obj나머지를 한 덩어리로

한 줄 정리

  1. 리액트에서 state가 배열이나 객체면 ...로 새로 만들어서 setState에 넘겨요.
  2. props는 매개변수 자리에서 구조분해로 꺼내 쓰면 코드가 짧아져요.
  3. useState의 [값, 함수]는 배열 구조분해라서 이름을 마음대로 지을 수 있어요.
