props 타입 지정, 처음부터

HTML 속성(attribute)을 다뤄 본 퍼블리셔 기준으로 설명합니다. 컴포넌트에 넘기는 값에 "어떤 값이 올 수 있는지" 약속을 거는 방법을 8단계로 익힙니다.

1단계

props는 컴포넌트의 속성입니다

HTML에서 <a href="/home" target="_blank">의 href, target이 속성이듯, 리액트 컴포넌트에 넘기는 size, onClick 같은 값을 props(properties)라고 부릅니다.

// HTML 속성
<a href="/home" target="_blank">홈</a>

// 컴포넌트 props
<Button label="저장" size="sm" disabled={false} />
퍼블리셔가 먼저 알아둘 규칙

값이 문자열이면 따옴표 "...", 그 밖의 값(숫자, true/false, 배열, 함수)은 중괄호 {...}로 넘깁니다.

2단계

타입이 없으면 실수를 아무도 알려주지 않습니다

자바스크립트는 props에 무엇이 들어오든 그대로 실행합니다. label을 lable로 잘못 써도, 숫자를 넣어도 화면이 조용히 이상해질 뿐입니다. 타입스크립트는 코드를 쓰는 순간 에디터에서 빨간 줄로 알려줍니다.

타입 없음JS
<Button lable="저장" />
// 오타인데도 에러가 없고
// 버튼이 빈 채로 나옵니다
타입 있음TS
<Button lable="저장" />
// 바로 빨간 줄:
// 'lable' 속성이 없습니다

props 타입은 "이 컴포넌트는 이런 값을 받습니다"라는 설명서이면서, 동시에 오타를 잡아주는 검사기입니다.

3단계

기본 형태는 세 줄이면 됩니다

① type으로 props의 모양을 정의하고, ② 컴포넌트에서 구조분해로 받고, ③ 콜론 뒤에 그 타입을 붙입니다.

// ① props의 모양을 정의합니다
type ButtonProps = {
  label: string;
  disabled: boolean;
};

// ②③ 받으면서 타입을 연결합니다
const Button = ({ label, disabled }: ButtonProps) => {
  return <button disabled={disabled}>{label}</button>;
};

// 사용
<Button label="저장" disabled={false} />

타입 이름은 컴포넌트이름Props로 짓는 것이 관례입니다. 이름은 자유지만 이 규칙을 따르면 다른 사람 코드도 바로 읽힙니다.

4단계

자주 쓰는 타입 일곱 가지

실무 컴포넌트의 props는 대부분 아래 일곱 가지로 끝납니다.

넘기는 값타입쓰는 모습

숫자numbercount={3}

배열string[]tags={["신규", "할인"]}

함수() => voidonClick={() => {}}

type CardProps = {
  title: string;
  price: number;
  soldOut: boolean;
  tags: string[];
  badge: { text: string; color: string };
  onBuy: () => void;
};
5단계

안 넘겨도 되는 props는 물음표

이름 뒤에 ?를 붙이면 선택 props가 됩니다. 넘기지 않으면 값이 undefined이므로, 받는 쪽에서 기본값을 정해 두면 편합니다.

type ButtonProps = {
  label: string;      // 필수
  disabled?: boolean; // 선택
};

const Button = ({ label, disabled = false }: ButtonProps) => (
  <button disabled={disabled}>{label}</button>
);

<Button label="저장" />                  // 정상, disabled는 false
<Button label="저장" disabled />         // 정상

기본값은 = false처럼 구조분해 자리에서 정합니다. 타입 쪽에는 쓰지 않습니다.

6단계

정해진 값 중 하나만 받게 하기

크기(sm, md, lg)나 색상(primary, ghost)처럼 "고정된 선택지 중 하나"인 props가 퍼블리싱에서는 가장 많습니다. 값을 |로 이어 쓰면 그 값만 허용됩니다. 이를 유니온 타입이라고 합니다.

type ButtonProps = {
  label: string;
  size?: "sm" | "md" | "lg";
  variant?: "primary" | "ghost";
};

const Button = ({ label, size = "md", variant = "primary" }: ButtonProps) => (
  <button className={`btn btn-${size} btn-${variant}`}>{label}</button>
);

아래에서 직접 값을 바꿔 보세요. size 칸에 mid처럼 목록에 없는 값을 입력하면 타입스크립트가 어떻게 막는지 볼 수 있습니다.

7단계

children과 함수 props

children은 컴포넌트 태그 사이에 넣은 내용입니다. 타입은 React.ReactNode로 쓰며, 글자와 태그를 모두 받을 수 있습니다. 받은 뒤 화면에 보이려면 {children}로 직접 출력해야 합니다.

type CardProps = {
  title: string;
  children: React.ReactNode;
};

const Card = ({ title, children }: CardProps) => (
  <div className="card">
    <h3>{title}</h3>
    {children}
  </div>
);

<Card title="공지">
  <p>점검 안내입니다.</p>
</Card>

함수 props는 "어떤 값을 받아서 무엇을 돌려주는 함수인가"를 화살표 모양으로 씁니다. 돌려주는 값이 없으면 void입니다.

type SearchBoxProps = {
  onClick: () => void;                // 받는 값 없음
  onSearch: (keyword: string) => void; // 글자 하나를 받음
};

<SearchBox
  onClick={() => console.log("click")}
  onSearch={(keyword) => console.log(keyword)}
/>
8단계

빨간 줄이 뜨면 이렇게 읽습니다

에러 문구는 영어지만 패턴은 네 가지뿐입니다. 아래 코드는 앞에서 만든 ButtonProps(label 필수, size는 sm | md | lg)를 기준으로 합니다.

<Button />
Property 'label' is missing in type '{}' but required in type 'ButtonProps'.

필수 props를 빠뜨렸습니다. 문구의 label이 빠진 이름입니다.

<Button label={3} />
Type 'number' is not assignable to type 'string'.

타입이 다릅니다. 숫자를 넣었는데 글자를 기대하는 자리입니다. "A는 B에 넣을 수 없다"로 읽으면 됩니다.

<Button label="저장" size="mid" />
Type '"mid"' is not assignable to type '"sm" | "md" | "lg"'.

허용하지 않는 값입니다. 문구 뒷부분에 쓸 수 있는 값 목록이 그대로 나옵니다.

<Button lable="저장" />
Property 'lable' does not exist on type 'IntrinsicAttributes & ButtonProps'.

정의하지 않은 이름입니다. 대부분 오타이므로 type에 적은 이름과 글자 단위로 비교해 보세요.

연습 문제

Badge 컴포넌트의 props 타입 만들기

아래 조건을 만족하는 BadgeProps를 직접 써 보고, 답과 비교해 보세요.

조건 1. text: 글자, 반드시 넘겨야 함

조건 2. color: "blue", "red", "gray" 중 하나, 안 넘기면 "gray"

조건 3. onClose: 받는 값이 없는 함수, 안 넘겨도 됨

정답 보기 
type BadgeProps = {
  text: string;
  color?: "blue" | "red" | "gray";
  onClose?: () => void;
};

const Badge = ({ text, color = "gray", onClose }: BadgeProps) => (
  <span className={`badge badge-${color}`}>
    {text}
    {onClose && <button onClick={onClose}>닫기</button>}
  </span>
);

선택 props인 onClose는 안 넘기면 undefined이므로, onClose && ...로 있을 때만 버튼을 그렸습니다.

정리

이 일곱 가지만 기억하세요

  • type 컴포넌트이름Props = { ... }로 모양을 정의하고 : 컴포넌트이름Props로 연결한다
  • 문자열은 따옴표, 나머지 값은 중괄호로 넘긴다
  • 기본 타입은 string, number, boolean, 배열, 객체, 함수
  • 안 넘겨도 되면 ?를 붙이고, 기본값은 구조분해 자리에서 정한다
  • 고정된 선택지는 "sm" | "md" | "lg"처럼 유니온으로 쓴다
  • 태그 사이 내용은 children: React.ReactNode로 받고 {children}로 출력한다
  • 에러는 "A는 B에 넣을 수 없다" 패턴으로 읽는다

다음 단계로는 button, input의 기본 속성(placeholder, disabled 등)을 그대로 이어받는 React.ComponentProps<"button">를 보시면 됩니다. 디자인 시스템 컴포넌트를 만들 때 자주 쓰입니다.
