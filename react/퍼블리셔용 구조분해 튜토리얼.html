구조분해, HTML 속성에서 출발하면 쉬워요

({ label, disabled }: ButtonProps) 처럼 생긴 코드가 낯설다면, 컴포넌트에 넘기는 속성이 어떻게 객체가 되는지부터 보면 금방 풀립니다.

1. 먼저 HTML 속성처럼 생각해보기

퍼블리싱할 때 <button disabled> 처럼 태그에 속성을 붙이죠. 리액트 컴포넌트도 똑같이 속성을 붙여 쓰고, 그 속성들은 객체 하나로 묶여서 컴포넌트 함수의 첫 번째 인자로 들어옵니다. 이 객체를 보통 props라고 불러요.

사용하는 쪽
// JSX에서 속성을 붙여 호출
<Button label="저장" disabled={true} size="lg" />
JSX 속성props 객체의 키값
label="저장"label"저장"
disabled={true}disabledtrue
size="lg"size"lg"

즉 Button 함수는 { label: "저장", disabled: true, size: "lg" } 라는 객체를 받습니다. 이제 남은 건 "이 객체에서 값을 어떻게 꺼내 쓰느냐"뿐이에요.

2. 구조분해는 객체에서 값을 꺼내 변수로 만드는 문법

CSS에서 var(--color)로 값을 꺼내 쓰는 것처럼, 객체에서도 이름으로 값을 꺼냅니다. 매번 props.label이라고 쓰는 게 번거로우니, 필요한 것만 한 번에 변수로 만들어두는 거예요.

하나씩 꺼내기
const props = { label: "저장", disabled: true };

const label = props.label;
const disabled = props.disabled;
구조분해로 한 번에 꺼내기 (위와 완전히 같은 결과)
const { label, disabled } = props;
기억할 규칙. 왼쪽의 { }는 객체를 만드는 게 아니라 꺼낼 이름 목록입니다. 이름은 객체의 키와 똑같이 써야 하고, 순서는 상관없어요.

3. 매개변수 자리에서 바로 꺼내기

컴포넌트 함수는 props를 첫 번째 인자로 받으니, 인자 자리에서 곧바로 구조분해할 수 있습니다. 이게 처음 질문하신 코드의 정체예요. 세 단계로 줄어드는 과정을 보세요.

1단계. props를 통째로 받고 점(.)으로 접근
const Button = (props: ButtonProps) => {
  return <button disabled={props.disabled}>{props.label}</button>;
};
2단계. 함수 안에서 구조분해
const Button = (props: ButtonProps) => {
  const { label, disabled } = props;
  return <button disabled={disabled}>{label}</button>;
};
3단계. 매개변수 자리에서 바로 구조분해 (실무에서 가장 많이 쓰는 형태)
const Button = ({ label, disabled }: ButtonProps) => {
  return <button disabled={disabled}>{label}</button>;
};

3단계에서는 props라는 이름이 아예 사라지는 점을 기억해두세요. 뒤의 실습에서 다시 나옵니다.

4. 타입스크립트에서 타입은 어디에 붙나요

: ButtonProps는 label이나 disabled 하나하나의 타입이 아니라, 구조분해하기 전의 객체 전체에 붙는 타입입니다. 괄호 { } 전체에 타입 하나를 붙이는 거예요.

Button.tsx
interface ButtonProps {
  label: string;
  disabled?: boolean;
}

const Button = ({ label, disabled }: ButtonProps) => { /* ... */ };
//             └ 꺼낼 이름 목록 ┘   └ 객체 전체의 타입 ┘

인터페이스를 따로 만들지 않고 그 자리에 바로 쓸 수도 있습니다.

const Button = ({ label, disabled }: { label: string; disabled?: boolean }) => { /* ... */ };
자주 하는 실수. 구조분해 안쪽에 타입을 쓰면 타입 지정이 아니라 이름 바꾸기가 됩니다. 
// label 값을 "string"이라는 변수에, disabled 값을 "boolean"이라는 변수에 담는다는 뜻
const Button = ({ label: string, disabled: boolean }) => { /* ... */ };

5. 실무에서 자주 만나는 변형 네 가지

기본값 주기

속성을 안 넘겼을 때 쓸 값입니다. 값이 undefined일 때만 적용돼요. false나 null을 넘기면 기본값이 쓰이지 않습니다.

({ label, disabled = false }: ButtonProps)

이름 바꾸기

콜론 앞이 객체의 키, 뒤가 새로 만들 변수 이름입니다. 이 경우 text만 변수가 되고 label이라는 변수는 생기지 않아요.

({ label: text }: ButtonProps)
// text === props.label

나머지 모으기 (...rest)

꺼내지 않은 나머지 속성을 객체 하나로 모읍니다. class, aria-label 같은 HTML 속성을 그대로 태그에 넘길 때 유용해요.

const Button = ({ label, ...rest }: ButtonProps) => (
  <button {...rest}>{label}</button>
);

children 꺼내기

여는 태그와 닫는 태그 사이의 내용은 children이라는 키로 들어옵니다. 퍼블리싱의 "내용이 들어갈 자리"와 비슷해요.

const Card = ({ children }: CardProps) => (
  <div className="card">{children}</div>
);

7. 확인 문제

Q1. const { a, b } = obj; 에서 obj에 b가 없으면 b는 어떻게 되나요?

undefined가 됩니다. 에러가 나지 않아요. 그래서 선택 속성에 기본값을 주는 문법(b = 0)이 의미가 있습니다.

Q2. ({ label: text }: ButtonProps) 에서 컴포넌트 안에서 쓸 수 있는 변수 이름은?

text만 쓸 수 있습니다. 콜론 앞의 label은 "어느 키에서 꺼낼지"를 가리킬 뿐이고, 변수로는 만들어지지 않아요.

Q3. ({ label }: ButtonProps) 로 받았을 때 함수 안에서 props.size로 접근할 수 있나요?

없습니다. 인자 자리에서 구조분해하면 props라는 이름 자체가 생기지 않아요. size가 필요하면 ({ label, size })처럼 꺼내거나 ...rest로 받아야 합니다.

한 장 요약

  • JSX 속성은 props 객체 하나로 묶여 함수의 첫 번째 인자로 들어옵니다.
  • { a, b } 는 객체에서 같은 이름의 키를 꺼내 변수로 만듭니다.
  • : ButtonProps 는 구조분해 전의 객체 전체에 붙는 타입입니다.
  • 기본값은 a = 값, 이름 바꾸기는 a: b, 나머지 모으기는 ...rest 입니다.
