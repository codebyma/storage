먼저 결론

라우터는 URL을 보고 보여 줄 화면을 고릅니다

라우터를 붙이려면 서로 다른 세 조각이 필요합니다. 각각 파일이 따로 있어서, 어느 파일이 무슨 일을 하는지만 알면 구조가 읽힙니다.

1. router 객체 (router.tsx): "이 URL이면 이 화면"을 적은 대응표입니다.

2. RouterProvider (App.tsx): 그 대응표를 앱 전체에 연결합니다.

3. Outlet과 Link (RootLayout과 각 화면): 자식 화면이 나올 자리, 그리고 화면을 옮기는 링크입니다.

설치

패키지는 react-router 하나입니다

v7부터는 react-router 하나에 필요한 기능이 모두 들어 있습니다. 예전에 쓰던 react-router-dom은 따로 설치하지 않아도 됩니다.

터미널
npm install react-router

이미 설치되어 있다면 package.json의 react-router 버전이 7 이상인지만 확인하세요. 가져오는 경로는 react-router로 통일하고, RouterProvider만 react-router/dom에서 가져옵니다.

파일 구조

어느 파일이 무슨 일을 하는지 먼저 봅니다

src 폴더
src/
├── main.tsx                  // 앱 시작점
├── App.tsx                   // RouterProvider 연결
├── app/
│   ├── layout/RootLayout.tsx // 모든 페이지가 공유하는 틀
│   └── routes/router.tsx     // URL과 페이지의 대응표
└── pages/
    └── style-guide/
        ├── index.ts          // 이 페이지 묶음의 공개 출입구
        └── ui/StyleGuidePage.tsx

브라우저에서 주소를 열면 화면이 나오기까지 다음 순서로 흘러갑니다.

주소 입력 (/style-guide)
   ↓
App.tsx 의 RouterProvider 가 router 를 받음
   ↓
router.tsx 에서 일치하는 라우트를 찾음
   ↓
RootLayout 을 먼저 그림
   ↓
RootLayout 안의 <Outlet /> 자리에 StyleGuidePage 를 그림
세팅 따라하기

파일 4개를 순서대로 만듭니다

1단계. main.tsx는 App을 화면에 올리는 보통의 시작점입니다. 라우터와 관련된 내용은 없습니다.

src/main.tsx
import { StrictMode } from 'react';
import { createRoot } from 'react-dom/client';
import App from './App';

createRoot(document.getElementById('root')!).render(
  <StrictMode>
    <App />
  </StrictMode>
);

2단계. App.tsx는 router를 RouterProvider에 넘기기만 합니다. 앱이 얇게 유지됩니다.

src/App.tsx
import { RouterProvider } from 'react-router/dom';
import { router } from '@/app/routes/router';

function App() {
  return <RouterProvider router={router} />;
}

export default App;

3단계. router.tsx에 대응표를 만듭니다. 처음에는 lazy 없이 가장 단순하게 시작합니다.

src/app/routes/router.tsx
import { createBrowserRouter } from 'react-router';
import { RootLayout } from '@/app/layout/RootLayout';
import { HomePage } from '@/pages/home';
import { StyleGuidePage } from '@/pages/style-guide';

export const router = createBrowserRouter([
  {
    path: '/',
    element: <RootLayout />,
    children: [
      { index: true, element: <HomePage /> },                  // /
      { path: 'style-guide', element: <StyleGuidePage /> },     // /style-guide
    ],
  },
]);

4단계. RootLayout에 Outlet을 둡니다. 자식 라우트의 화면은 이 자리에 나옵니다.

src/app/layout/RootLayout.tsx
import { Outlet } from 'react-router';

export const RootLayout = () => {
  return (
    <div>
      <header>공통 헤더</header>
      <main>
        <Outlet />   {/* 여기에 index, style-guide 화면이 들어옴 */}
      </main>
    </div>
  );
};

여기까지 하고 npm run dev로 열면 /와 /style-guide가 각각 다른 화면으로 보입니다.

라우트 읽는 법

라우트 객체의 속성은 다섯 개면 충분합니다

속성뜻예
path이 라우트가 맡는 주소 조각'style-guide'
element주소가 맞을 때 그릴 화면<StyleGuidePage />
children이 라우트 안에 들어가는 자식 라우트[ ... ]
index부모 주소와 딱 맞을 때 보여 줄 기본 화면index: true
path: '*'어떤 라우트와도 맞지 않을 때 (404 화면)'*'

자식의 path는 부모 주소 뒤에 이어 붙는 상대 경로입니다. 맨 앞에 /를 쓰지 않습니다. 부모가 '/'이고 자식이 'style-guide'면 최종 주소는 /style-guide입니다.

이동하기

링크는 Link, 코드로 이동은 useNavigate

라우트를 정의했다고 링크가 자동으로 생기지는 않습니다. 화면 안에서 직접 이동 수단을 넣어야 합니다.

링크 만들기
import { Link, NavLink, useNavigate } from 'react-router';

// 1. 일반 링크
<Link to="/style-guide/colors">색상 가이드</Link>

// 2. 현재 주소와 맞으면 스타일을 바꾸고 싶은 메뉴
<NavLink
  to="/style-guide"
  className={({ isActive }) => (isActive ? 'menu on' : 'menu')}
>
  스타일 가이드
</NavLink>

// 3. 버튼을 눌렀을 때 코드에서 이동
const navigate = useNavigate();
<button onClick={() => navigate('/style-guide')}>이동</button>
방법언제 쓰나
Link클릭하면 이동하는 일반 링크
NavLink메뉴처럼 "지금 보는 곳"을 표시해야 할 때
useNavigate폼 제출 후 이동처럼 코드가 이동을 결정할 때
<a href>외부 사이트로 나갈 때만. 내부 이동에 쓰면 페이지 전체가 새로고침됩니다.
동적 경로

주소 일부를 변수로 받을 수 있습니다

path에 콜론(:)을 붙이면 그 자리가 변수가 됩니다. 글 상세 페이지처럼 모양은 같고 값만 다른 화면에 씁니다.

// router.tsx
{ path: 'posts/:id', element: <PostPage /> }

// PostPage.tsx
import { useParams } from 'react-router';

export const PostPage = () => {
  const { id } = useParams();   // /posts/42 로 들어오면 id 는 "42"
  return <div>{id}번 글</div>;
};

id는 항상 문자열입니다. 숫자로 쓰려면 Number(id)로 바꿔야 합니다.

lazy 로딩

페이지를 필요할 때만 불러옵니다

지금 프로젝트처럼 lazy와 Suspense를 쓰면 해당 주소에 들어갈 때 그 페이지 코드를 따로 내려받습니다. 첫 화면이 가벼워집니다.

import { lazy, Suspense } from 'react';

const StyleGuidePage = lazy(() =>
  import('@/pages/style-guide').then((m) => ({ default: m.StyleGuidePage }))
);

const withSuspense = (element: React.ReactNode) => (
  <Suspense fallback={<div>로딩중...</div>}>{element}</Suspense>
);

// children 안에서
{ path: 'style-guide', element: withSuspense(<StyleGuidePage />) }

lazy는 default export를 기대합니다. 페이지가 named export라서 .then으로 { default: ... } 모양으로 바꿔 줍니다. default export라면 lazy(() => import('./StyleGuideHome'))처럼 바로 쓸 수 있습니다.

페이지 추가

새 페이지를 붙일 때 고칠 곳은 네 군데입니다

  • pages/이름/ui/ 안에 페이지 컴포넌트를 만듭니다.
  • pages/이름/index.ts에서 그 컴포넌트를 export 합니다.
  • router.tsx에 lazy import를 추가합니다.
  • router.tsx의 children에 { path, element } 한 줄을 추가합니다.

이동 링크가 필요하면 Link를 별도로 넣습니다. 위 네 가지만으로는 주소창에서 직접 접속할 때만 열립니다.

자주 나는 문제

막혔을 때 먼저 확인할 네 가지

페이지는 열리는데 본문이 비어 있음

RootLayout에 <Outlet />이 없는지 확인하세요. 자식 화면은 Outlet 자리에만 그려집니다.

Module '"./StyleGuideHome"' has no exported member 'StyleGuideHome'.

export 방식과 import 방식이 다릅니다. export default는 import X from으로, export const는 import { X } from으로 가져옵니다. default를 named로 내보내려면 index.ts에 export { default as X } from './ui/X'를 씁니다.

배포 후 /style-guide 에서 새로고침하면 404

개발 서버는 알아서 처리하지만, 배포한 서버는 /style-guide라는 실제 파일을 찾습니다. 모든 주소를 index.html로 돌려주도록 호스팅 설정(rewrite, try_files 등)을 해야 합니다.

react-router 와 react-router-dom 이 파일마다 섞여 있음

동작은 하지만 하나로 통일하는 편이 안전합니다. v7이라면 react-router에서 가져오고, RouterProvider만 react-router/dom에서 가져옵니다.

연습 문제

왜 /style-guide/colors 가 404일까요?

아래처럼 만들었더니 /colors로는 열리는데 /style-guide/colors는 404입니다. 이유를 생각해 보세요.

{
  path: '/',
  element: <RootLayout />,
  children: [
    { path: 'style-guide', element: <StyleGuidePage /> },
    { path: 'colors', element: <ColorGuidePage /> },
  ],
}
정답 보기

자식의 path는 부모 주소 뒤에 이어 붙습니다. 부모가 '/'이므로 'colors'는 /colors가 됩니다. /style-guide/colors로 열고 싶다면 path: 'style-guide/colors'로 쓰거나, style-guide 라우트 안에 children을 만들어 { path: 'colors' }를 넣으면 됩니다.

정리

기억할 다섯 가지

  • 라우터는 router 객체(대응표), RouterProvider(연결), Outlet(자식 자리) 세 조각입니다.
  • 자식 라우트의 path는 부모 뒤에 붙는 상대 경로이고, 맨 앞에 /를 쓰지 않습니다.
  • /에 화면을 두려면 index: true를 씁니다.
  • 이동은 Link, NavLink, useNavigate로 하고, 라우트 정의만으로는 링크가 생기지 않습니다.
  • 새 페이지는 컴포넌트, index.ts, lazy import, children 한 줄 순서로 붙입니다.
