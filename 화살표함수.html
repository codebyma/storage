1

기본 문법

화살표 함수는 function 대신 =>를 쓰는 짧은 함수 표기입니다. 아래 5단계로 일반 함수가 어떻게 줄어드는지 따라가 봅니다.

JavaScript
function add(a, b) {
  return a + b;
}

1단계가장 익숙한 형태입니다. 여기서 출발합니다.

JavaScript
const add = function (a, b) {
  return a + b;
};

2단계함수를 변수에 담았습니다. 화살표 함수는 이름 없는 표현식이라 항상 이 형태로 씁니다.

JavaScript
const add = (a, b) => {
  return a + b;
};

3단계function 키워드를 지우고 매개변수 뒤에 =>를 붙입니다.

JavaScript
const add = (a, b) => a + b;

4단계본문이 식 하나뿐이면 중괄호와 return을 지웁니다. 식의 결과가 곧 반환값입니다.

JavaScript
const square = n => n * n;

5단계매개변수가 하나뿐이면 괄호도 지울 수 있습니다. 0개이거나 2개 이상이면 괄호가 필요합니다.

return 없이 값 반환하기

본문이 식 하나면 그 결과가 반환값이 됩니다. 매개변수 개수에 따라 괄호 규칙이 달라집니다.

JavaScript
const add = (a, b) => a + b;        // 중괄호와 return 생략
const square = n => n * n;          // 매개변수가 하나면 괄호 생략
const hello = () => "안녕하세요!";    // 매개변수가 없으면 빈 괄호

console.log(add(10, 5));
console.log(square(7));
console.log(hello());
출력
15
49
안녕하세요!

객체 리터럴 반환하기

중괄호는 함수 본문으로 읽힙니다. 객체를 바로 돌려주려면 소괄호로 감쌉니다.

JavaScript
// 객체 리터럴을 바로 반환하려면 소괄호로 감싼다
const makeUser = (name, age) => ({ name, age });

// 소괄호가 없으면 중괄호가 함수 본문으로 해석된다
const broken = (name) => { name };

console.log(makeUser("민지", 28));
console.log(broken("민지"));
출력
{"name":"민지","age":28}
undefined

2

배열 메서드와 함께

화살표 함수가 가장 자주 쓰이는 곳입니다. 콜백이 한 줄로 끝나서 데이터가 흘러가는 모양이 바로 보입니다.

map, filter, reduce

가격 목록에 세금을 붙이고, 1만 원 이상만 고르고, 합계를 구합니다.

JavaScript
const prices = [12000, 8500, 23000, 4900, 17500];

const withTax = prices.map(p => Math.round(p * 1.1));
const expensive = prices.filter(p => p >= 10000);
const total = prices.reduce((sum, p) => sum + p, 0);

console.log(withTax);
console.log(expensive);
console.log(total);
출력
[13200,9350,25300,5390,19250]
[12000,23000,17500]
65900

sort, find, some, every

정렬 기준과 조건 검사도 화살표 함수 한 줄이면 됩니다. sort는 원본을 바꾸므로 복사본에 씁니다.

JavaScript
const users = [
  { name: "하준", age: 31, active: true },
  { name: "서연", age: 24, active: false },
  { name: "도윤", age: 27, active: true },
];

const byAge = [...users].sort((a, b) => a.age - b.age);
const firstActive = users.find(u => u.active);

console.log(byAge.map(u => u.name));
console.log(firstActive.name);
console.log(users.some(u => u.age > 30));
console.log(users.every(u => u.active));
출력
["서연","도윤","하준"]
하준
true
false

메서드 체이닝으로 주문 집계

filter, map, reduce를 이어 붙여 2개 이상 주문한 품목의 금액을 객체로 모읍니다.

JavaScript
const orders = [
  { item: "커피", qty: 2, price: 4500 },
  { item: "케이크", qty: 1, price: 6800 },
  { item: "샌드위치", qty: 3, price: 5200 },
];

const summary = orders
  .filter(o => o.qty >= 2)
  .map(o => ({ item: o.item, amount: o.qty * o.price }))
  .reduce((acc, o) => ({ ...acc, [o.item]: o.amount }), {});

console.log(summary);
출력
{"커피":9000,"샌드위치":15600}

3

this가 다른 점

화살표 함수는 자기만의 this를 만들지 않고 바깥 범위의 this를 그대로 씁니다. 일반 함수는 호출 방식에 따라 this가 바뀝니다.

setTimeout 안에서의 this

같은 메서드 안에서 콜백만 다르게 썼을 때 this가 객체를 가리키는지 비교합니다.

JavaScript
const timer = {
  seconds: 0,
  startWithFunction() {
    setTimeout(function () {
      // 일반 함수: 호출 방식에 따라 this가 달라진다
      console.log("function:", this === timer);
    }, 10);
  },
  startWithArrow() {
    setTimeout(() => {
      // 화살표 함수: 바깥 this를 그대로 쓴다
      console.log("arrow:", this === timer);
    }, 20);
  },
};

timer.startWithFunction();
timer.startWithArrow();
출력
function: false
arrow: true

클래스 필드로 this 고정하기

화살표 함수를 클래스 필드로 두면 메서드를 변수에 떼어 내도 this가 인스턴스에 묶여 있습니다.

JavaScript
class Counter {
  count = 0;
  increment = () => {
    this.count += 1;
    return this.count;
  };
}

const counter = new Counter();
const { increment } = counter;   // 메서드를 떼어 내도 this가 유지된다

console.log(increment());
console.log(increment());
출력
1
2

4

콜백과 비동기

then 콜백과 async 함수 모두 화살표 함수로 간결하게 쓸 수 있습니다. 출력은 시간이 지나면서 차례로 나타납니다.

async 화살표 함수

async를 화살표 앞에 붙입니다. then 체인과 await 방식을 나란히 둡니다.

JavaScript
const wait = ms => new Promise(resolve => setTimeout(resolve, ms));

const fetchUser = async id => {
  await wait(30);
  return { id, name: `사용자 ${id}` };
};

fetchUser(1)
  .then(user => console.log("then:", user.name));

(async () => {
  const user = await fetchUser(2);
  console.log("await:", user.name);
})();
출력
then: 사용자 1
await: 사용자 2

Promise.all과 결과 순서

끝나는 시각이 달라도 결과 배열은 넘겨 준 순서를 지킵니다.

JavaScript
const delay = (ms, value) =>
  new Promise(resolve => setTimeout(() => resolve(value), ms));

Promise.all([delay(40, "A"), delay(10, "B"), delay(20, "C")])
  .then(results => console.log(results));
출력
["A","B","C"]

함수를 돌려주는 함수

화살표 함수는 함수를 반환하는 코드를 한 줄에 쓸 수 있어서 커링, 합성, 캐시 같은 패턴과 잘 어울립니다.

커링

인자를 하나씩 나누어 받아서 일부만 채운 새 함수를 만듭니다.

JavaScript
const multiply = a => b => a * b;

const double = multiply(2);
const triple = multiply(3);

console.log(double(8));
console.log(triple(8));
console.log([1, 2, 3].map(multiply(10)));
출력
16
24
[10,20,30]

pipe로 함수 이어 붙이기

작은 변환 함수를 순서대로 통과시켜 URL용 문자열을 만듭니다.

JavaScript
const pipe = (...fns) => x => fns.reduce((v, fn) => fn(v), x);

const slugify = pipe(
  s => s.trim(),
  s => s.toLowerCase(),
  s => s.replace(/\s+/g, "-")
);

console.log(slugify("  Arrow Functions In JS  "));
출력
arrow-functions-in-js

memoize로 계산 결과 재사용

같은 입력은 저장해 둔 값을 돌려주므로 실제 계산은 한 번만 일어납니다.

JavaScript
const memoize = fn => {
  const cache = {};
  return n => (n in cache ? cache[n] : (cache[n] = fn(n)));
};

let calls = 0;
const slowSquare = memoize(n => {
  calls += 1;
  return n * n;
});

console.log(slowSquare(9), slowSquare(9), slowSquare(9));
console.log("실제 계산 횟수:", calls);
출력
81 81 81
실제 계산 횟수: 1

매개변수 다루기

기본값, 구조분해, 나머지 매개변수는 화살표 함수에서도 일반 함수와 똑같이 동작합니다.

기본값과 구조분해

매개변수 자리에서 바로 기본값을 주고, 객체를 풀어서 받습니다.

JavaScript
const greet = (name = "고객", { honorific = "님" } = {}) =>
  `${name}${honorific}, 환영합니다`;

console.log(greet());
console.log(greet("지우"));
console.log(greet("지우", { honorific: "선생님" }));

const fullName = ({ first, last }) => `${last}${first}`;
console.log(fullName({ first: "서준", last: "김" }));
출력
고객님, 환영합니다
지우님, 환영합니다
지우선생님, 환영합니다
김서준

나머지 매개변수

인자 개수가 정해지지 않았을 때는 ...args로 받아서 배열처럼 다룹니다.

JavaScript
const sum = (...nums) => nums.reduce((a, b) => a + b, 0);
const max = (...nums) => Math.max(...nums);

console.log(sum(1, 2, 3, 4));
console.log(max(4, 19, 7));
console.log(sum());
출력
10
19
0

7

쓰면 안 되는 곳

화살표 함수는 일반 함수를 모두 대신하지 못합니다. 아래 세 경우에는 일반 함수나 메서드 문법을 씁니다.

객체 메서드

화살표 함수의 this는 객체가 아니라 바깥 범위입니다.

JavaScript
const person = {
  name: "수아",
  regular() { return this === person; },
  arrow: () => this === person,
};

console.log(person.regular());
console.log(person.arrow());
출력
true
false

주의객체에 붙이는 메서드는 regular()처럼 메서드 문법으로 씁니다.

생성자

화살표 함수는 new로 호출할 수 없습니다.

JavaScript
const Point = (x, y) => ({ x, y });

try {
  new Point(1, 2);
} catch (e) {
  console.log(e.constructor.name);
}
출력
TypeError

주의new로 만들 대상은 function이나 class로 선언합니다.

arguments 객체

화살표 함수에는 자기 arguments가 없습니다. 나머지 매개변수가 그 자리를 대신합니다.

JavaScript
function legacy() { return arguments.length; }
const modern = (...args) => args.length;

console.log(legacy(1, 2, 3));
console.log(modern(1, 2, 3));
출력
3
3

주의화살표 함수 안에서 arguments를 쓰면 바깥 함수의 arguments를 가리킵니다. 의도하지 않았다면 ...args로 바꾸세요.

한눈에 정리

상황별로 어느 쪽을 고르면 되는지 모았습니다.

상황권장이유
map, filter 같은 콜백화살표 함수짧게 쓰고, 본문이 식 하나면 return도 생략됩니다.
setTimeout이나 이벤트 핸들러에서 바깥 this 사용화살표 함수바깥 this를 그대로 쓰므로 bind가 필요 없습니다.
한 줄짜리 변환 함수, 유틸 함수화살표 함수const로 선언해 이름을 붙이면 재사용하기 쉽습니다.
객체의 메서드메서드 문법화살표 함수의 this는 객체가 아닙니다.
new로 만드는 생성자function 또는 class화살표 함수를 new로 호출하면 TypeError가 납니다.
인자 전체를 arguments로 접근일반 함수 또는 ...args화살표 함수에는 자기 arguments가 없습니다.
